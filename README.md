# 카톡 릴레이

[![다운로드](https://img.shields.io/github/v/release/mjsob/kakao-relay?label=%EB%82%B4%EB%A0%A4%EB%B0%9B%EA%B8%B0&color=FEE500&labelColor=1A1500)](https://github.com/mjsob/kakao-relay/releases/latest/download/kakao-relay-setup.zip)
[![설치 가이드](https://img.shields.io/badge/%EC%84%A4%EC%B9%98%20%EA%B0%80%EC%9D%B4%EB%93%9C-%EB%B3%B4%EA%B8%B0-8A5A00)](https://claude.ai/code/artifact/cb5553e1-f521-4090-828f-b68b28bc5559)

**앱을 설치할 수 없는 휴대폰에서 문자 한 통을 보내면, 켜 둔 PC의 카카오톡이 같은 내용을 대신 전송합니다.**

```
발신 휴대폰 ──문자──▶ 중계 휴대폰 ──Wi-Fi──▶ PC 릴레이 ──▶ 카카오톡
```

### 이런 경우에 씁니다

- 손에 든 휴대폰에 카카오톡을 설치하거나 실행할 수 없습니다
- 그 휴대폰으로 문자는 보낼 수 있습니다
- 늘 켜 두는 Windows PC가 있고, 쓰지 않는 안드로이드 공기계가 한 대 있습니다

셋 다 맞으면 **20분** 안에 설치할 수 있습니다. 프로그램은 무료입니다.

카카오톡 계정은 쓰던 것을 그대로 씁니다. 별도 로그인이나 외부 서버를 거치지 않습니다.

## 준비물

| | |
|---|---|
| PC | Windows 10 이상. **설정 > 시스템 > 디스플레이 > 배율**이 **100%** 여야 합니다 |
| PC 카카오톡 | 로그인한 상태, 화면잠금 해제 |
| 중계 휴대폰 | 안드로이드 공기계 + [MacroDroid](https://play.google.com/store/apps/details?id=com.arlosoft.macrodroid). **문자를 받을 수 있는 유심**이 꽂혀 있어야 합니다 |
| 네트워크 | PC와 중계 휴대폰이 같은 Wi-Fi |

중계 휴대폰은 문자를 받아 같은 Wi-Fi의 PC로 넘기는 역할만 합니다.
문자를 받는 것은 무료지만, 결과를 문자로 돌려받도록 설정하면 **보내는 요금**이 듭니다.

## 설치

**[kakao-relay-setup.zip 내려받기](https://github.com/mjsob/kakao-relay/releases/latest/download/kakao-relay-setup.zip)**

지금 쓰는 판은 **카톡 릴레이** 창의 작업 표시줄 이름과 **상태 점검** 첫 줄에서 확인할 수 있습니다.

압축을 풀고 `KakaoRelay.bat`을 실행한 뒤 **설치하기**를 누르세요.

중계 휴대폰은 [완성된 매크로 파일](https://github.com/mjsob/kakao-relay/releases/latest/download/kakao-relay.macro)을
MacroDroid 메인 화면의 **백업 · 복원 > 업로드**로 가져온 뒤, **IP 주소**와 **발신 번호** 두 곳만 고치면 됩니다.

설치 직후에는 **시험 모드**라 카카오톡으로 실제 전송하지 않습니다.
문자를 한 통 보내 어느 채팅방으로 갈지 확인한 뒤, 조작 창에서 **시험 모드 해제**를 누르세요.

**이미 쓰고 있다면** 압축을 푸는 것만으로는 다 반영되지 않습니다.
설치 가이드의 [새 판으로 올리기](docs/설치가이드.html)를 따라 주세요.

PC와 휴대폰 양쪽 설정은
[설치 가이드](https://claude.ai/code/artifact/cb5553e1-f521-4090-828f-b68b28bc5559)에 모두 들어 있습니다.
링크가 열리지 않으면 저장소의 [docs/설치가이드.html](docs/설치가이드.html)을 내려받아 브라우저로 여세요.

## 문자 보내는 방법

**맨 처음 띄어쓰기**가 채팅방 이름과 내용을 구분합니다.

```
엄마 오늘 좀 늦어요
   ↑    ↑
채팅방  보낼 내용
```

첫 띄어쓰기 뒤는 무엇이든 그대로 전달됩니다.
띄어쓰기가 더 있어도, `http://` 같은 주소나 `3/4일` 같은 날짜가 들어 있어도 손대지 않습니다.

채팅방 이름에 띄어쓰기가 있으면 `개발팀단톡방`처럼 붙여서 적거나, 설정에 별칭을 등록하세요.

### 같은 사람에게 계속 보내기

`@`로 채팅방을 한 번 지정해 두면, 그 뒤로는 이름 없이 내용만 보내도 계속 그 방으로 갑니다.

```
@엄마            대상을 엄마로 지정
오늘 좀 늦어요     → 엄마
집에 다 왔어      → 엄마
@               지정을 풀어 원래대로
```

지정해 둔 동안에는 문자 전체가 보낼 내용이 됩니다. 보내는 사람마다 따로 기억하며, 릴레이를 다시 켜도 유지됩니다.

대상을 정할 때 릴레이가 **카카오톡에서 그 방을 실제로 찾아본 뒤에만** 지정합니다.
이름이 틀렸다면 지정하지 않고 직전 대상을 그대로 두므로, 잘못된 이름이 지정된 채 이후 문자가 줄줄이 실패하는 일이 없습니다.
이름 일부만 적었다면 카카오톡에 있는 정확한 이름으로 잡힙니다.

### 전달 결과를 문자로 받기

중계 휴대폰을 설정해 두면, 알려줄 일이 생겼을 때만 보낸 사람에게 문자로 답장이 옵니다.

| 상황 | 보낸 사람에게 |
|---|---|
| 정상 전달 | 문자 없음 |
| `@`로 대상 지정 · 변경 · 해제 | 지금 지정된 채팅방을 알려줍니다 |
| 채팅방을 찾지 못함 · 전달 실패 | 실패한 이유를 알려줍니다 |
| `@`로 없는 채팅방을 지정 | 지정하지 않고 그대로 두었음을 알려줍니다 |
| PC 꺼짐 · Wi-Fi 끊김 | 전달되지 않았음을 알려줍니다 |

답장은 모두 `[카톡]`으로 시작합니다. 중계 휴대폰이 릴레이의 답인지 구분하는 데 쓰는 표식입니다.

```
@엄마   →  [카톡] 대상 지정
           엄마
           풀려면 @ 한 글자
@형     →  [카톡] 대상 변경
           엄마 → 형
@       →  [카톡] 대상 해제
           엄마 → 해제
           이제 첫 낱말이 방 이름
```

답장 한 통마다 문자 요금이 듭니다. 부담이면 설정에서 `"smsReply": false`로 끌 수 있습니다.
지금 지정된 대상은 **카톡 릴레이** 창에서도 볼 수 있습니다.

설정 방법은 [설치 가이드](https://claude.ai/code/artifact/cb5553e1-f521-4090-828f-b68b28bc5559)의 **결과를 문자로 돌려받기**에 있습니다.

## 미리 알아둘 점

| 상황 | 동작 |
|---|---|
| PC 전원 꺼짐 · 절전 | 릴레이가 멈춥니다 |
| Windows 로그아웃 | 릴레이도 함께 종료됩니다 |
| Windows 잠금 화면 (`Win+L`) | 키보드 입력이 잠금 화면으로 넘어가 카카오톡에 글자를 넣지 못합니다 |
| 카카오톡 로그아웃 · 화면잠금 | 카카오톡을 조작할 수 없습니다 |
| 사진 · 파일 | 문자 본문만 전달합니다 |
| 장문 (MMS) | 전달되지 않습니다. 짧게 나누어 보내세요 |
| 전송 결과 회신 | 중계 휴대폰을 설정하면 전달 실패와 지정한 대상을 문자로 알려줍니다 |
| 같은 내용 반복 | 5분 안에 같은 문자를 다시 보내면 두 번째는 전달하지 않습니다 |

카카오톡 PC 버전은 계정 하나당 한 대에서만 로그인됩니다.
다른 PC에서도 같은 대화를 봐야 한다면 계정을 하나 더 준비하세요.

## 동작 방식

카카오톡은 자동화용 API를 제공하지 않으므로, Win32 메시지로 창을 직접 조작합니다.

- 채팅방을 검색해 열고, 입력창에 글자를 넣고, 전송 버튼을 누릅니다
- 전송이 끝나면 창을 닫습니다. 열어 두면 그 방에 **새로 오는 메시지까지 계속 읽음 처리**되기 때문입니다
- 릴레이가 멈추면 1분 안에, 응답하지 않는 상태면 2분 안에 저절로 다시 실행됩니다

실측으로 알아낸 내부 동작과 함정은 [개발 기록](docs/개발기록.md)에 정리해 두었습니다.

## 설치하면 생기는 것

| 항목 | 설명 |
|---|---|
| 조작 창 | 켜고 끄기, 상태 점검, 설정 편집, 기록 확인을 한곳에서 합니다 |
| 알림 영역 아이콘 | 조작 창을 열거나 릴레이를 끝냅니다 |
| 예약 작업 2개 | 로그온할 때 실행하고, 1분마다 살아 있는지 확인합니다 |
| 방화벽 규칙 | 중계 휴대폰이 접속할 포트를 엽니다 (개인 네트워크 전용) |

설정 파일과 기록은 설치한 폴더 안에만 만들어집니다. 외부로 나가는 통신은 없습니다.
바탕 화면에 바로가기가 하나 생깁니다.

## 지우기

`program` 폴더의 `Uninstall.ps1`을 **마우스 오른쪽 버튼 클릭 > PowerShell로 실행**하세요.
프로그램을 내리고 예약 작업 2개, 방화벽 규칙, 바탕 화면 바로가기를 지웁니다.
기록과 설정을 함께 지울지는 물어봅니다. 그 뒤 폴더를 통째로 지우면 끝입니다.

기록에는 주고받은 문자 내용이, 설정에는 전화번호가 남아 있으니 확인하고 지우세요.

## 안 될 때

설치 가이드의 **09 문제 해결**에 증상별로 정리해 두었습니다.
그 전에 조작 창의 **상태 점검**을 먼저 눌러 보세요. 문제가 있는 항목만 찾아 알려 줍니다.
